{{ ic('ic-data', 'ic-sm ic-quiet') }} Export fields

FieldMeaning
message_idStable 12-hex id; the permalink is /m/{id}. It does not change between builds.
thread_idThe id of the thread's first message; the thread page is /t/{id}.
poster_idThe person id (addresses and name variants grouped). In a pseudonymized export, a pseudonym.
poster_nameThe name as posted on this message. In a pseudonymized export, the same pseudonym as poster_id.
date_utc, year, monthThe Date header in UTC; year and month as filed (the log's month when the header disagrees with it).
genreQuery, discussion, debate, CFP, job ad, announcement, tribute, list business, or other; see the Genres page for how labels are made and how accurate they are.
subject, bodyAs posted, with addresses removed.
body_own_wordsThe body without quoted text (> lines, forwarded and "Original Message" blocks) or the signature block. Heuristic; see the methodology.
permalinkThe message's URL in this reader.

Exports and saved corpora are capped at {{ "{:,}".format(export_max) }} messages. Messages withdrawn at a poster's request are never included. Pseudonyms are stable for one corpus or one exact search, so re-downloading gives the same ones, and differ between corpora. Pseudonymization covers the name and id fields only: names inside message text (signatures, "X wrote:" lines) remain.

API

Read-only JSON, versioned under /api/v1/, {{ api_rate }} requests a minute per client, {{ api_page }} results a page. Withdrawn messages and people are absent here too.

GET /api/v1/messages/{id}One message, with its citations.
GET /api/v1/threads/{id}A thread and its messages.
GET /api/v1/search?q=&from=&start=&end=&fresh=1&page=The search page's filters; fresh=1 matches own words only. Includes a next link.
GET /api/v1/corpus/{id}A saved corpus: its query, build, frozen ids, and a page of messages.
GET /api/v1/posters/{id}A person with a public page: names as posted, activity, affiliations.
